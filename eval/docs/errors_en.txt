Quillon X2 router error code reference. Error E-4471 means the WAN link is down; check the cable and restart the modem. Error E-4472 means the DHCP server did not respond; reset the router to factory settings. Error E-5130 indicates overheating, and the router will shut down when its internal temperature exceeds 85 degrees Celsius. Error E-6008 means the firmware update failed; hold the reset button for 15 seconds and try again. Error E-7421 means the Wi-Fi password is shorter than 8 characters. Contact support if an error persists after a restart.
